# Values (written from how we actually operate)
1. Make something people want. Building is cheap now; building the wrong thing is the only real cost.
2. Ship to production. If no real user has it, it doesn't exist.
3. Product moves at the speed of feedback.
4. Talk to real users every week, and count it.
5. Remove before you add. Simplify, then validate.
6. Follow the pull.
7. Less planning, more building. Do things that don't scale.
8. "I'll just do it."

Goose rewrites these from what it sees the founder actually do.
