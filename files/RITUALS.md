# Rituals

# The one thing we always do
Build a simpler version and get feedback. Product and positioning. Prototypes over plans. Iterative progress every week.

# Daily
- Morning: what are we shipping today, and which real user sees it?
- Capture any feedback or user connection, verbatim.

# Weekly
- Build a simpler version of the product or the positioning and put it in front of real users.
- Friday review: weekly questions, shipped, connections, feedback themes, pull, one cut, next week's simpler version.

# Monthly
- Default alive or default dead.
- Is this still the thesis, mission, and strategy?
- Reread values against how we actually behaved.

# Quarterly
- Rewrite strategy and responsibilities from what actually happened.
