# Templates: the company folder

Goose keeps these files current without being asked. Each starts with a "Last confirmed" date. Short beats complete. Mission, values, responsibilities, and rituals are published above; these are the rest, as empty skeletons.

## shipped.md
Everything that reached production, and who saw it.
```
# Shipped to production
(date, what, who saw it)
```

## users.md
Every real connection with a user or customer. This is the counter.
```
# Users and customers we talked to
(date, who, what we learned)

## Count by week
```

## feedback.md
Feedback captured verbatim, how people actually used it, and what we learned.
```
# Feedback
## Raw (who, what they said, date)
## Themes
## Insight and action
```

## pull.md
Evidence of real pull: people coming back, asking, paying.
```
# Where the pull is
(evidence of people coming back, asking, paying)
```

## metrics.md
The weekly answers, the one metric, and the monthly default alive check.
```
# Weekly YC questions
(shipped, users talked to, one metric and growth, surprise, blocker, next goal)

# One metric

# Default alive or dead (monthly)
```

## projects.md
Every idea, project, and team of people and agents, and whether it's moving.
```
# Ideas, projects, and teams (people and agents)
(name | owner | status | next step | moving or stuck)
```

## strategy.md
This quarter's bet, the one metric, and what we're not doing.
```
# This quarter's bet
# The one metric that shows pull (target 5-7% weekly growth)
# What we are NOT doing
```
